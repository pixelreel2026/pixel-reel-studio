# Pixel & Reel Studio - Creative AI Platform

منصة احترافية لتوليد الصور والفيديوهات بالذكاء الاصطناعي مع نظام إدارة اشتراكات متقدم.

## 🚀 الميزات الرئيسية

### 🎨 توليد المحتوى
- **توليد الصور بالذكاء الاصطناعي** - تصاميم متعددة وأنماط مختلفة
- **توليد الفيديوهات والريلز** - محتوى فيديو احترافي
- **تصاميم متقدمة** - خيارات تخصيص شاملة

### 💳 نظام الاشتراكات
- **3 خطط اشتراك** - مجاني، احترافي، مؤسسي
- **نظام الأرصدة الديناميكي** - تتبع الاستخدام الفوري
- **تكامل Stripe** - دفع آمن وموثوق

### 📊 لوحة التحكم
- **إدارة الأرصدة** - عرض الرصيد المتبقي
- **سجل الاستخدام** - تتبع جميع العمليات
- **إدارة الفواتير** - تحميل وتتبع الفواتير
- **الإعدادات المتقدمة** - تخصيص كامل للحساب

### 🌍 التوافقية
- **دعم كامل RTL** - العربية والإنجليزية
- **تصميم متجاوب** - يعمل على جميع الأجهزة
- **واجهة عصرية** - تأثيرات حركية احترافية

## 🛠️ المتطلبات التقنية

- **Node.js** 18+ 
- **pnpm** 10+
- **MySQL** 8+
- **AWS S3** (اختياري - للتخزين)

## 📦 التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/yourusername/pixel-reel-studio.git
cd pixel-reel-studio

# تثبيت التبعيات
pnpm install

# إعداد متغيرات البيئة
cp .env.example .env
# عدّل .env بمعلوماتك

# تشغيل قاعدة البيانات
pnpm db:push

# تشغيل التطوير
pnpm dev
```

## 🚀 الإنشاء والنشر

```bash
# بناء المشروع
pnpm build

# تشغيل الإنتاج محلياً
pnpm start

# النشر على Netlify
netlify deploy --prod
```

## 🔧 متغيرات البيئة

تأكد من تعيين المتغيرات التالية:

```env

DATABASE_URL=mysql://user:password@host/database

# Stripe
STRIPE_SECRET_KEY=sk_...
STRIPE_PUBLISHABLE_KEY=pk_...

# AWS S3
AWS_ACCESS_KEY_ID=...
AWS_SECRET_ACCESS_KEY=...
AWS_S3_BUCKET=...

# AI Services
OPENAI_API_KEY=sk-...

# التحليلات
VITE_ANALYTICS_ENDPOINT=...
VITE_ANALYTICS_WEBSITE_ID=...
```
